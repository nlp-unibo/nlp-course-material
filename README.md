# Natural Language Processing

The official repository for the NLP Course held by Prof. Torroni at UniBO.

## Contents

One folder per academic year. Each assignment is a notebook, its slides, and the data it needs.

### 2026-2027

| Material | Task | Dataset | Methods |
|---|---|---|---|
| Assignment 1 | Unfair clause detection, multi-label over 5 categories | [ToS-100](https://doi.org/10.5281/zenodo.22691656) | GloVe, BiLSTM, LEGAL-BERT |
| Assignment 2 | Fallacy detection, multi-label over 3 categories | [MAFALDA](https://github.com/ChadiHelwe/MAFALDA) | LLM zero-/few-shot prompting |
